# 乐信（lexin）

一个微信界面美化模块，Xposed / LSPosed 用的。

- 包名：`io.github.lex0m.lexin`
- 作者：lex
- 协议：MIT
- 当前版本：v1.1

## 这版干了啥

主页跑 8.0.78，拿官方 APK 一个版本一个版本装上去点，都记在下面的表里。表里那六行都是这么点出来的，8.0.79、8.0.77、8.0.76、8.0.74、8.0.72 这版补上。入口识别重写过，老版本也能自己找着。随机数那块在 8.0.79 / 8.0.77 上找回准地方了，骰子猜拳结果能直接写死；8.0.76 和更老的版本这个入口没找着，那就降级——骰子结果照改，选择框还在，不硬凑。广告拦截基本能清干净，个别版本只剩小程序那一条漏网。最后，遇上表里没有的微信版本，模块会自己在设备上扫 dex，扫不到的功能安静跳过，不崩，也不带着微信一起坏。

## 能干啥

一块是界面。全屏背景，图片随便挑，透明度可调，填充 / 适应 / 拉伸 / 居中 / 自定义裁剪五种缩放；列表卡片化，左右内缩、圆角、上下间隔、卡片高度都能自己调；状态栏恢复系统原色，不再被背景图压住；顶部栏跟着背景走，切页和下拉都不错位。聊天页不动它，微信自己的聊天背景和气泡原样保留。

一块是日常小功能：防撤回、朋友圈保留、去广告（含朋友圈）、自动查看原图、骰子猜拳结果自己定、放宽本地限制。开关全在设置面板里，不用的东西关掉就行。

## 装法

1. 装上 `lexin.apk`
2. LSPosed 里勾上「乐信」，作用域选**微信**
3. 重启微信 —— 强制停止再打开就够了，不用重启手机

环境：Android 12 – 15，LSPosed 或别的兼容 Xposed 框架，微信 8.0.x。

## 打开设置面板

三个入口，用哪个顺手用哪个：

1. LSPosed 模块页右下角的 ▶ 启动按钮
2. 桌面上的「乐信」图标
3. 微信里：我 → 设置 → 更多 → 关怀模式 → 长按「开启」

第三个最隐蔽，也最容易被微信改版搞没，平时用前两个更省事。面板里每项都标了是立刻生效、还是得重进界面。

## 支持情况

下表是拿官方 APK 一个个装到机器上实测出来的，不是看代码猜的：

| 微信版本 | versionCode | 适配情况 |
| --- | --- | --- |
| 8.0.79 | 3200 | 防撤回 / 朋友圈 / 表情 / 原图 / 入口 全通；随机数入口 platformtools.v8；广告只剩小程序 |
| 8.0.78 | 3180 | 全部适配（7/7），本机实测版本 |
| 8.0.77 | 3160 | 防撤回 / 朋友圈 / 表情 / 原图 / 入口 全通；随机数 platformtools.v8；广告只剩小程序 |
| 8.0.76 | 3140 | 防撤回 / 朋友圈 / 表情 / 原图 / 入口 全通；随机数入口没找到（骰子结果改写降级，选择框还在）；广告降级 |
| 8.0.74 | 3120 | 同 8.0.76 |
| 8.0.72 | 3100 | 防撤回 / 表情 / 原图 / 入口 全通；朋友圈库没命中；随机数与广告降级 |

表里没有的版本也大概率能用：模块会在设备上自己扫微信的 dex，扫完缓存下来，扫不到的那项安静跳过，不会崩，也不会拖着微信和其它功能一起坏。因为是首次启动才扫，装完第一次可能要多重启一次微信，功能才全部到位。
