# 乐信（lexin）

微信的 Xposed / LSPosed 模块。界面美化 + 几个实用小功能，全部只在本机生效。

- 包名：`io.github.lex0m.lexin`
- 作者：lex

- 当前版本：**v1.1**

## 三个主力功能

### 一、消息防撤回（双向）

别人撤回的消息，**原样留在聊天里**，不会被换成「xxx撤回了一条消息」。

做法是在微信解析撤回指令的地方把那条指令抹掉 —— 指令不成立，微信就不去改写原消息。
不发请求、不改上行报文，服务端那边什么都不知道。

被撤回的消息会标出来：气泡压暗一点，**气泡正下方**贴一个小胶囊写「对方撤回」。
标签是画在行的 overlay 上的，不参与布局、不会挤压气泡；位置每次重排都重新量，
所以切后台回来也不会跑位。自己撤回不贴标签（微信本来就有提示，再叠一个就是两个提示打架）。

### 二、运动步数修改（三种模式）

**三种模式分开，互不影响：**

| 模式 | 效果 |
| --- | --- |
| 直接指定步数 | 今天就是那个数，立刻生效（比如填 12000，微信运动读到 12000） |
| 自动增加 | 每小时自动加 N 步，随时间平滑涨，像真在走路 |
| 倍率 | 按真实步数放大（1.2 倍 ~ 5 倍） |

都带**额外步数上限**（默认 20000，可选到 80000），超了就停在上限，不会出现一眼假的天文数字。

**做法是走外部通道，不碰微信的数据接口：**

1. 优先挂在**微信自己算出来的"今天步数"**上 —— 各家手机的步数来源不一样（小米读 MIUI 的
   content provider、其它品牌多半读系统计步器），微信内部已经做过适配，挂在它的结果上就与品牌无关，
   换手机不用改规则；
2. 挂不上就退回**框架传感器层**（`SystemSensorManager$SensorEventQueue.dispatchSensorEvent`），
   在数据分发出去之前改掉累计值，微信一行代码都不碰；
3. 微信自己听计步器的那两条路（`MMSportStepDetector` / `PushSportStepDetector`）也一起挂上。

这里有个容易踩的数学坑写出来给后来人：微信算的是「今天的累计 − 今天第一次读到的累计」，是个**差值**。
给累计值加一个固定偏移会被减掉、等于没改。所以「直接指定」走的是**一次性注入增量**，
不是加常数。

### 三、去广告

| 位置 | 做法 |
| --- | --- |
| 朋友圈信息流 | 掐掉广告对象的构造（`plugin.sns.storage.ADInfo`），条目根本进不了时间线 |
| 小程序开屏 | 广告判定一律答"否" |
| 开屏广告 | 同上，挂在判定点上 |

全部只拦本地决策点，不改任何网络请求。三处归属**同一个开关**（面板里的「屏蔽广告位」）。

## 其它功能

- **朋友圈保留**：对方删掉的评论和动态，本机留副本（只拦朋友圈表上的 DELETE，其它 SQL 原样放行）
- **解除扫码限制**：相册选图、长按图片识别二维码不再受微信那层限制（按"相机"场景处理）
- **自动查看原图**：浏览图片时自动切原图
- **放宽本地限制**：表情包数量、消息多选、状态字数上限
- **骰子 / 猜拳自选**：长按表情面板里的骰子或猜拳，弹框选点数/出拳，也可以保持随机
- **界面美化**：全屏背景（透明度/五种缩放/自定义裁剪）、列表卡片化、聊天条独立成卡（配图、圆角、内缩、模糊）、毛玻璃、状态栏与顶部栏跟随背景
- **设置面板顶部**：每日一言（每次打开换一句，诗词/古籍/技术/幽默混着来）+ 当前登录微信的头像昵称

## 装

1. 装 `lexin.apk`
2. LSPosed 里勾选「乐信」，作用域勾微信
3. 强行停止微信再打开

## 打开设置面板（三种都行）

1. **LSPosed → 模块 → 乐信 → 右下角 ▶ 按钮**
2. 桌面「乐信」图标
3. 微信里：我 → 设置 → 更多 → 关怀模式 → **长按「开启」**（隐藏入口）

首次打开会强制阅读两秒免责声明（含禁止国内网络传播条款），读过就不再出现。

## 支持微信版本

| 微信版本 | versionCode | 适配情况 |
| --- | --- | --- |
| 8.0.79 | 3200 | 全部适配；实测表已内置 |
| **8.0.78** | **3180** | **全部适配（9/9），本机实测** |
| 8.0.77 | 3160 | 全部适配 |
| 8.0.76 | 3140 | 全部适配；随机数入口没找到（骰子结果改写降级，选择框还在） |
| 8.0.74 | 3120 | 同 8.0.76 |
| 8.0.72 | 3100 | 防撤回 / 表情 / 原图 / 扫码 / 入口 全通；朋友圈库没命中 |

表里没有的微信版本也不用慌：模块会自己在设备上扫 dex，按「类名特征 + 方法内字符串 + 方法签名」三层
指纹找落点，扫到的结果缓存到本机，下次启动零成本。找不到的功能安静跳过，不崩、也不带着微信一起坏。
